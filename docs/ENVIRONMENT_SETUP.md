# Environment Setup

Use Python 3.11 or newer and install `python3 -m pip install -e '.[dev]'`. Runtime packages are `jsonschema`, `pdfplumber`, `pytesseract`, and `Pillow`; development packages are `pytest`, `pytest-cov`, `ruff`, `mypy`, `types-jsonschema`, and `pre-commit`. The source PDF repository is an external read-only input and is never copied into this release.
